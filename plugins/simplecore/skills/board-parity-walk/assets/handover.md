# Facts a walker needs to start

Read this when a walking session opens. It exists so that what one walker worked out is not worked
out again by the next.

Only **what is true now** goes here. No point of view — not "I found", not "this time", not "it
used to be". A fact that changes is corrected in place, with no history left behind. What a walk
felt like belongs in that walker's own log, never here.
