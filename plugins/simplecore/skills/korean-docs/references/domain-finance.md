# 금융·퀀트·트레이딩 도메인 용어

금융 · 퀀트 · 트레이딩 도메인의 문서 · 코드 · 주석을 다룰 때 [response-style.md](response-style.md)에 더해 적용한다. 그 분야 작업이 아니면 읽지 않는다. 영어 용어를 음차하거나 직역해 어색한 표현을 만들지 않는다. 한국 금융 실무 · 학계에 정착된 용어를 쓰고, 정착 용어가 없으면 풀어 쓴다.

### 음차 남발 금지

| 금지 | 대체 |
| ---- | ---- |
| `브레드스`(breadth) | 시장 폭 |
| `험프`(hump) | (유동성 깊이) 정점 |
| `프린트`(print, 체결 기록) | 체결값, 체결 기록 |
| `틸트`(tilt) | 비중 기울임, 비중 확대 |
| `리더`(leading stocks) | 주도주 |
| `헤드라인`(headline 수치) | 대표 수치, 전체 |
| `오버레이`(analysis overlay) | 보조분석 |
| `레짐`(regime) | 국면 (시장 국면, 급락 국면, 국면 단절, 국면 게이트) |
| `드로다운`(drawdown) | 낙폭, 급락 |

**낱말로 등재된 것은 넷뿐이다** — `브레드스` · `험프` · `레짐` · `드로다운`. 나머지 다섯은 금융 밖에서
쓰는 뜻이 정상어라(인쇄하는 프린트, 카메라의 팬·틸트, 팀 리더와 카드 리더, 기사 헤드라인, 화면
오버레이) 낱말만으로는 갈리지 않으므로, 갈라 주는 앞말과 함께 등재했다: `체결 프린트` · `비중 틸트` ·
`가치 틸트` · `팩터 틸트` · `모멘텀 틸트` · `리더 종목` · `헤드라인 수치` · `헤드라인 지표` ·
`분석 오버레이`. **앞말이 없는 자리는 사람이 본다** — 금융 문서에서 이 다섯 낱말을 만나면 무엇을
가리키는지 확인하고 위 표의 대체어로 고친다.

### 직역 금지·주의

- **`모사(模寫)` 금지** — `simulation`은 「시뮬레이션」, 또는 정착 표현 「모의」(모의투자, 모의 체결)를 쓴다. `체결 모사` → 「체결 시뮬레이션」.
- **`함의`(implied) 금지** — 「내재」를 쓴다. `implied volatility` → 「내재 변동성」, 내재 수익률, 내재 바스켓.
- **`effective` 번역 주의** — microstructure의 `effective spread`(2×|체결가−mid|)는 「유효 스프레드」로 정착돼 있으나, 「실제 체결 가능한 호가차」(executable bid/ask)를 뜻할 때 「유효 스프레드」를 쓰면 혼동된다. 후자는 **「체결 가능 스프레드」**로 명시한다. `effective leverage`는 「실효 레버리지」.
- **`regime break`** → 「국면 단절」 (econometrics 맥락은 「구조적 단절」).
- **`book`(주문장) 직역 금지** — `책` 금지. 「호가창」으로 쓴다(「호가창이 얇아진다」).
- **`dominated` 직역 주의** — `한국 지배`(Korea-dominated)(✖)는 「한국 주도」로. 시장 맥락의 `dominate`는 `지배`가 아니라 「주도」.
- **`hard` 직역 주의** — `하드 손절` → 「강제 손절」, `하드 상한` → 「절대 상한」, `하드 레짐 단절` → 「명백한 국면 단절」. 단, 「하드코딩」은 정착어로 유지.
- **영어 비유(metaphor) 직역 금지** — plumbing → `배관`(✖)은 「통제 체계」·「기반 규칙」으로, let winners run → `승자 주행`(✖)은 「수익 포지션을 끝까지 끌고 감」으로, hazard sim → `해저드 모사`(✖)는 「장애 시뮬레이션」으로, aggressiveness dial → `공격성 다이얼`(✖)은 「공격성 자동 조절」로 쓴다.
- **압축 직역 금지** — `단절 넘는 생존을 보고`(✖)처럼 영어 명사구를 압축 직역하지 말고 「단절 전후에도 살아남는지 확인한다」처럼 풀어 쓴다. `가산 선형`(additive linear) → 「선형 합산」, `비중복분`(incremental/non-overlapping part) → 「중복되지 않는 부분, 추가 기여분」.

### 정착 용어는 유지 (과잉 교정 금지)

엣지, 슬리피지, 레이턴시, 커버리지, 바스켓, 포지션, 프록시, 리밸런스, 잔차, 직교, 괴리, 편입/편출, 내재 변동성, 음의 자기상관, 실효 레버리지, 페어/스탯아브, 페이드(매매 맥락), 게이트 등은 그대로 쓴다.

처음 등장하는 전문 영어 약어·고유명(NBBO, OU, HAC, ATS 등)은 음차하지 말고 영문 그대로 두되, 필요하면 첫 등장 시 한 번 풀어 쓴다.

※ 기본 용어사전의 `레버리지 → 활용` 규칙은 이 도메인과 충돌한다. 금융 프로젝트의 용어사전에서는 `## 기본 규칙 예외`에 `레버리지`를 등재해 비활성화한다. **이 기준을 적어 두는 저장소도 마찬가지다** — 도메인 용어를 지정하려면 그 낱말을 적어야 하므로, 이 파일을 담은 저장소의 용어사전에도 같은 예외가 필요하다. 기준을 적었다는 이유로 기준을 어긴 것이 되면 스킬이 제 감사를 통과할 수 없다.
