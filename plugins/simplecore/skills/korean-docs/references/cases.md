# Cases behind the rules

The accounts that made a rule of this skill necessary. Each rule keeps its sentence and its reason
where it lives; this file holds what happened, so a reader who doubts a rule can see the run that
produced it. Read it when a rule looks too strict to be worth its cost, or before narrowing one.

## The sweep's closing line

Rule: `SKILL.md`, The audit - a lens candidate is read the moment it is printed.

One coordinator swept eight reports in a day, read `Clean` eight times, and never opened the ten
candidates listed above it. `가족` for a font family was among them every time, and it reached the
user.

## A zero from the rules on a board

Rule: `references/reading-lens.md` - a rule catches only the forms registered in it, so the lens
selects candidates for a person.

The skill had rules and nothing else for a long time. Seventy-two rules returned zero on a board,
and when a person read it in filename order one cluster alone gave fourteen findings, none of which
any rule had caught.

## Korean prose in a figure generator

Rule: `references/audit-tooling.md`, The write-time hook - a directory sweep reads documents and
declared kinds, so a project that keeps Korean in code names those paths in its own check list.

One document's generators held thirty-seven findings on their first reading, every one of them in
prose a person had reviewed more than once.

## Glossary rows

- **`face` and `font family`** were registered from a user correction. For `font family`,
  `서체군` was the other candidate, was not chosen, and is banned with the rest of the row.
- **`꼴`**: one repository held thirty-nine occurrences of 「글꼴」 alone, which is why a compound
  with Hangul in front of `꼴` is never caught.
- **`다치 술어`**: the row once fixed 「다치」 while leaving 「술어」, which endorsed the
  mistranslation. Both words are now matched together.

## A screen rule read against a manual

Rule: `RULES.base.json`, `can-instead-of-does` - 「~할 수 있습니다」 is judged in the screen
register only.

On a 119-file manual the rule fired 467 times, and every hit was a capability sentence. As lens
candidates the same sentences were a wall, not reading material.

## Question-form labels

Rule: `RULES.base.json`, `question-as-field-label`.

In one repository ninety-seven question-form labels remained after every screen name had been fixed.

## The stand family right after an audit

Rule: `RULES.base.json`, `bodyless-stands`.

A session that fixed 829 findings in files wrote `서버 절반이 섰습니다` in the report on that very
work.

## The tooling

- **`audit.exclude` reaching a declared kind** (`scripts/l10n.mjs`, `discover`): one repository's 278
  review records, excluded because they quote each round's sentences verbatim, came back through a
  kind glob as the sentence sweep's largest source of findings, and every one of them was a file
  nobody may edit.
- **A reflowed flow sequence in the front matter** (`scripts/lib/glossary.mjs`,
  `gatherFlowSequence`): the audit went on reporting 「오류 0건」 while its file count fell from 407
  to 86, and nothing on screen distinguished that from a clean run.
