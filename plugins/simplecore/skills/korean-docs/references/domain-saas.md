# Subscription · billing · licensing terms

Applied on top of [response-style.md](response-style.md) when working on documents, screen copy, or
comments for a subscription, billing, or licensing product. Do not read it for other work.

**The audit applies the table below in a project whose glossary declares the field**: `domains:
[saas]` under `audit:` in its front matter. The same declaration switches on the rule pack's `saas`
scope (`RULES.base.json`), so the field's words and its sentence rules load together. The table has
the base glossary's format (`GLOSSARY.base.md`), and a project turns one row off through its own
`## 기본 규칙 예외` table.
